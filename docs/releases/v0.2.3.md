# 국가별 공식 방송사와 재생 개선

- 국가 안에서 **공식 방송사**, **개인·독립 방송**, **운영자 미확인**, **전체** 탭을 전환할 수 있습니다. 공식 방송사가 확인된 국가에서는 해당 탭이 먼저 열립니다.
- 방송 상세에서 확인된 운영자와 근거를 볼 수 있습니다. 원래 프로그램을 만든 방송사와 인터넷으로 중계하는 곳을 구분하고, 북한 프로그램을 중계하는 방송에는 북한 국가 코드를 적용했습니다.
- KBS·MBC·SBS·YTN·JTV의 공식 송출 주소를 연결했습니다. 만료된 재생 주소, 구형 인터넷 라디오 서버, 일반 재생 목록 처리도 개선했습니다.
- 작은 창에서는 다이얼이 남은 높이에 맞춰 줄어듭니다. 방송 목록을 스크롤하는 동안에도 수신기 아래 눈금과 재생 버튼을 볼 수 있습니다. 반복되던 **ON AIR**, **LIVE**, **방송을 선택해** 문구를 정리했습니다.

### 11월 13일 방송 점검

국내 회선에서 223개 국가·지역의 전체 등록 항목 53,628건을 조사했습니다. 48,209건에서 송출 데이터를 받았고 5,239건은 재점검 후에도 확인되지 않았습니다. 공개 재생 주소가 아닌 항목 등 180건은 직접 접속 대상에서 제외했습니다. 최초 점검과 재확인 결과, 중계처와 운영자 정보는 국가별·방송별 점검표에서 볼 수 있습니다.

등록 목록에서 방송사로 확인한 항목은 3,753건, 개인·독립 방송은 1,598건입니다. 나머지 48,277건은 운영자 미확인으로 표시합니다. 앱에는 국내 방송사 직결 채널 13개도 제공합니다. [전 세계 방송 점검표 다운로드](https://github.com/samueltoken/Allradione/releases/download/v0.2.3/Allradione-Station-Audit-0.2.3.zip)
