# Allradione 0.2.5

- 설정에서 한국어, 영어, 일본어, 중국어 간체, 광둥어, 대만 번체 중국어, 대만어(민난어), 라틴어를 선택할 수 있습니다. 방송국 이름과 채팅 메시지는 원문을 유지합니다.
- 백그라운드 재생을 켜 두면 위젯 없이도 창을 닫고 계속 들을 수 있습니다. 트레이에서 앱을 다시 열거나 완전히 종료할 수 있습니다.
- 데스크톱 위젯은 기존 크기까지 확대하거나 가장자리를 끌어 축소할 수 있습니다. 좁아지면 방송명과 재생 조작을 우선합니다.
- 채팅창의 기본 폭을 넓히고 크기 조절을 추가했습니다. 닉네임 옆에는 채팅에 참여하는 동안 실제로 듣고 있는 방송과 국기가 표시됩니다.
- 메시지를 선택해 신고할 수 있습니다. 관리자는 신고 원문을 확인하고, 전송 간격이나 전체 채팅 잠금을 설정하고, 사용자를 일시 또는 영구 차단할 수 있습니다.
- 0.2.5부터 앱 안에서 업데이트를 시작하면 검증한 Windows 설치 마법사를 직접 엽니다. 0.2.4에서 0.2.5로 넘어가는 첫 업데이트는 기존 0.2.4의 방식으로 시작합니다. 즐겨찾기와 설정은 유지합니다.
