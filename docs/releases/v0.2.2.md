업데이트 버튼이 설치 대신 릴리스 다운로드 페이지를 열던 문제를 수정했어.

- 업데이트 실행 시 최신 설치 파일 정보를 다시 확인하고, 앱 안에서 다운로드·검증·설치 후 자동으로 다시 시작해.
- 설치 파일 업로드가 아직 끝나지 않았으면 재확인할 수 있도록 표시해.
- 다운로드나 설치 준비에 실패했을 때 완료로 표시하지 않고 다시 시도할 수 있어.
- 설치 도우미의 준비 완료를 확인한 후 앱을 종료하고, 설치 후 재실행도 확인하도록 보강했어.
- Windows 설치·업데이트 검증과 파일 업로드가 모두 끝난 뒤에 새 릴리스를 공개하도록 변경했어.

기존 설정·즐겨찾기·최근 청취 기록은 유지돼. 디자인과 재생 기능은 변경하지 않았어.

v0.2.0·v0.2.1 설치 버전은 **Settings → 업데이트 확인 → 다운로드 및 설치**로 업데이트할 수 있어. 이전에 다운로드 페이지가 열렸다면 Settings를 닫았다 다시 열고 업데이트를 확인해줘. 이전 v0.1.x 무설치 버전은 이번 설치 파일을 한 번 실행해야 해.
