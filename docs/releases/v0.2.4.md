# Allradione 0.2.4

- 큰 창에서는 넓은 원호로 방송을 고르고, 실제 소리에 맞춰 점무늬가 움직입니다. 작은 창은 원형 다이얼을 사용합니다.
- 홈과 모든 국가·분류 화면에 전체 채팅을 추가했습니다. 오른쪽 아래 빨간 버튼으로 열고 접을 수 있습니다. 닉네임을 비워 두면 Ano 번호를 사용합니다.
- 방송사가 직접 게시한 주소와 재송출 주소를 대조해 운영자 분류를 보완했습니다. 방송 정보에서 확인 근거와 미확인 사유를 볼 수 있습니다.
- NHK WORLD-JAPAN은 공식 송출표와 한국어 편성표를 사용합니다. 이전 목록의 잘못된 출력 번호를 바로잡고, 방송 사이에는 다음 편성 시각을 표시합니다.
- 일부 RADIO BOB!, FluxFM, VRT 등에서 음성을 받기 전에 연결이 끊기던 문제를 수정했습니다. 재생이 어려운 방송은 오류 원인을 표시하고 국가 목록 아래에서 다시 시도할 수 있습니다.
- 업데이트 확인 버튼의 화살표 방향을 바로잡았습니다. 누르면 제자리에서 시계 방향으로 한 바퀴 돕니다.

현재 설치본의 **설정 → 업데이트 확인**에서 다운로드와 설치를 시작할 수 있습니다.
