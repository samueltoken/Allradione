# Allradione 전체 채팅

방송 재생은 청취자의 PC에서 처리합니다. 사용자가 채팅을 열면 공용 방에 접속하고, 접으면 연결을 닫습니다. 방에는 닉네임, 메시지, 현재 재생 중인 방송 이름과 국가 코드가 공유됩니다. 음성, 송출 주소, 청취 기록은 전송하지 않습니다. 사용자는 다른 사용자를 숨기거나 메시지를 신고할 수 있습니다.

## 로컬 검사

프로젝트 루트에서 다음 명령을 실행하면 독립된 시험용 방에서 두 접속자의 대화와 신고 처리를 검사합니다.

```sh
npm ci --prefix chat
node --test chat/test.cjs
```

## 배포와 신고 처리

배포 설정은 Allradione 계정에 고정되어 있습니다. 이 PC의 PowerShell에서는 아래 명령으로 프로젝트 전용 인증을 사용합니다.

```powershell
$env:XDG_CONFIG_HOME = Join-Path $env:LOCALAPPDATA 'Allradione-Cloudflare'
Set-Location chat
node node_modules/wrangler/bin/wrangler.js deploy
```

닉네임 입력칸에서 `관리자`를 입력하면 로그인 창이 열립니다. 권한은 서버가 확인하며, 접속을 끊거나 한 시간이 지나면 다시 로그인해야 합니다. 관리자는 신고 당시의 원문과 닉네임을 확인하고 전송 간격, 전체 입력 제한, 사용자 차단을 설정할 수 있습니다. 차단은 서버가 발급한 익명 사용자 식별자에 적용되므로 닉네임 변경에는 유지되지만, 기기나 앱 데이터를 바꾼 사람까지 식별하지는 못합니다.

관리자 아이디와 비밀번호의 원문을 저장하지 않습니다. 클라이언트는 PBKDF2-SHA256(60만 회)으로 로그인 증명을 만들고 TLS로 전달합니다. 서버는 별도 무작위 소금값과 PBKDF2-SHA256(10만 회)을 사용하여 Cloudflare의 `ADMIN_VERIFIER` Secret과 비교합니다. 로그인 증명 자체도 비밀번호처럼 다뤄야 합니다. 공개 저장소나 로그에 쓰지 마세요.

관리자 로그인 정보를 바꾸려면 프로젝트 루트에서 `node chat/set-admin.cjs`를 실행하세요. 관리자 아이디와 새 비밀번호는 표시되지 않으며 원문을 파일이나 명령줄에 쓰지 않습니다. 설치된 앱을 업데이트하지 않아도 다음 로그인부터 새 정보가 적용됩니다. 이미 로그인한 세션은 로그아웃하거나 한 시간이 지나면 끝납니다.

기존 `POST /moderate` 관리 도구는 별도의 `MODERATOR_KEY` Secret으로 인증합니다. 이 키를 데스크톱 앱에 포함하지 마세요.
